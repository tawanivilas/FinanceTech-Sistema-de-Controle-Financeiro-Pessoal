# FinanceTech – Sistema de Controle Financeiro Pessoal

##  Sobre o projeto

O **FinanceTech – Sistema de Controle Financeiro Pessoal** foi desenvolvido para a disciplina de **Produto de Software**.

O projeto tem como objetivo criar uma ferramenta para **registrar, organizar e acompanhar as entradas e saídas de dinheiro**, permitindo ao usuário ter maior clareza sobre sua situação financeira.

A proposta é auxiliar no controle do orçamento, no acompanhamento dos gastos, na organização das receitas e despesas e, futuramente, no planejamento financeiro.

## 🎯 Objetivo

O FinanceTech busca facilitar o controle das finanças pessoais por meio de um sistema simples e organizado.

O usuário poderá utilizar o sistema para:

* 💰 Registrar receitas
* 💸 Registrar despesas
* 🏷️ Organizar categorias
* 🏦 Controlar contas
* 🎯 Criar metas financeiras
* 📋 Gerenciar transações
* 📊 Visualizar relatórios
* 📈 Acompanhar a evolução financeira

A partir dos dados cadastrados, o sistema poderá apresentar gráficos e informações que ajudam o usuário a entender **para onde o dinheiro está indo**.

# 🗄️ Banco de dados

O FinanceTech utiliza **MySQL** para armazenamento das informações do sistema.

Entre os dados armazenados estão informações relacionadas aos usuários e aos lançamentos financeiros.

O banco de dados é executado utilizando **Docker**, facilitando a configuração do ambiente de desenvolvimento.

---

# 🔐 Segurança

O sistema utiliza mecanismos de segurança para o armazenamento das senhas dos usuários, evitando que as senhas sejam armazenadas diretamente em texto puro no banco de dados.
